# Приложение: "Заметки"
## Некоторые использованные виджеты
1. `ListView` - для отображения списка записей на домашней странице
2. `TextFormField` - для редактирования записей
3. `ElevatedButton` - кнопочки
4. `Navigator` - навигация между страницами
5. `Provider` - сохранение состояния
